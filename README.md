# website-claude-code

Kilang website premium dengan Claude Code: prompt ringkas → website dengan animasi profesional, glassmorphism, gradient dan layout yang polished.

Dikuasakan oleh:
- **UI UX Pro Max**: design system automatik (gaya, warna, font, struktur, UX)
- **21st.dev**: komponen React/Tailwind siap pakai melalui MCP
- **Skill `website-builder`**: aliran kerja 8 langkah dari brief hingga deploy

## Mula

1. Tetapkan `API_KEY_21ST` (kunci percuma di https://21st.dev/mcp).
2. Buka repo dalam Claude Code dan luluskan pelayan MCP `21st`.
3. Taip, contohnya: `Bina landing page untuk <bisnes anda>, gaya premium glassmorphism, Bahasa Melayu.`

Panduan penuh: [docs/PANDUAN.md](docs/PANDUAN.md)

Setiap website disimpan dalam `sites/<nama-website>/`.
