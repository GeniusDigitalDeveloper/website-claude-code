APK agent AndroidBoleh pada telefon dan tablet Android apa-apa jenama. Buka aplikasi: kamera terus terbuka, imbas kod QR dari panel admin.
Muat turun APK

Pautan APK dibuka di GitHub dan repo ini persendirian: log masuk GitHub dahulu dalam pelayar yang sama, jika tidak GitHub papar 404. Pasang dengan benarkan "pemasangan dari sumber tidak dikenali". Untuk iPhone, Mac, Linux dan peranti lain, guna agent.html. Paparan sebenar fail di tab sebelah. Firebase tidak disambung di sini, jadi senarai peranti kosong. Index terbuka terus tanpa log masuk; admin memerlukan e-mel dan kata laluan.
