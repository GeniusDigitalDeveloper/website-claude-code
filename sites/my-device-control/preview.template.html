MY DEVICE CONTROL

Satu pakej siap salin: index.html, admin.html, rules Firestore, rules Database dan Cloud Functions. Ikut langkah 1 hingga 8, salin setiap fail dengan satu klik.

Preview hidup

Ini paparan sebenar fail index.html dan admin.html. Admin dalam mod demo dengan data contoh yang dilabel jelas; tiada Firebase disambung di sini.

1

Sediakan Firebase (sekali sahaja)

Buka Firebase Console → projek my-devide-control:

  1. Build → Authentication → Get started → Sign-in method: aktifkan Email/Password (dan Google jika mahu). Tab Users: tambah akaun admin anda (e-mel + kata laluan).
  2. Build → Firestore Database → Create database (Production mode, pilih lokasi).
  3. Build → Realtime Database → Create database (Locked mode). Catat URL-nya (https://…firebasedatabase.app).
  4. Upgrade ke pelan Blaze (perlu untuk Cloud Functions; guna percuma dalam kuota kecil).
2

Rules Firestore

Firestore Database → tab Rules → padam semua kandungan → tampal → Publish.

3

Rules Realtime Database

Realtime Database → tab Rules → padam semua → tampal → Publish.

4

Cloud Functions (backend: arahan, enrollment, peranan)

Semua arahan sensitif melalui backend yang menyemak peranan. Fungsi tidak boleh digantikan dengan HTML sahaja.

  1. Pasang Node.js 20 kemudian:
    npm i -g firebase-tools firebase login
  2. Buat folder projek, contoh my-device-control/, dan simpan 4 fail ini (struktur):
    my-device-control/ firebase.json firestore.indexes.json functions/index.js functions/package.json
  3. Edit functions/index.js: tukar GANTI@emel-anda.com kepada e-mel admin anda (boleh banyak, pisah dengan koma). Hanya e-mel ini boleh mencipta organisasi pertama.
  4. Deploy:
    cd my-device-control firebase use my-devide-control (cd functions && npm install) firebase deploy --only functions,firestore:indexes
Selepas deploy, indeks mengambil beberapa minit untuk siap. Jika deploy gagal kerana APIs, benarkan prompt untuk mengaktifkan API.
5

Ambil firebaseConfig

  1. Firebase Console → ⚙ Project settings → General → Your apps → Add app → Web (</>). Beri nama, jangan pilih Firebase Hosting.
  2. Salin blok const firebaseConfig = {…}. Pastikan ada databaseURL (jika tiada, ambil dari Realtime Database dan tambah).
  3. Nanti, bila buka index.html kali pertama, tampal blok itu pada skrin "Sambung Firebase". Tiada kod perlu diedit. (Atau isi pemalar CONFIG di dalam index.html dan admin.html.)
  4. Authentication → Settings → Authorized domains: tambah domain Interactive Link anda.
Kunci config web ini bukan rahsia. Keselamatan dikawal oleh rules + backend. Jangan sekali-kali letak service account dalam HTML.
6

index.html & admin.html (satu fail lengkap setiap satu)

Salin setiap satu, simpan dengan nama index.html dan admin.html dalam folder yang sama, kemudian muat naik kedua-duanya ke Interactive Link. Tiada langkah build, tiada Node di hosting.

7

Guna buat kali pertama

  1. Buka laman anda → tampal firebaseConfig → Simpan & sambung.
  2. Log masuk dengan akaun admin (e-mel yang sama dalam BOOTSTRAP_ADMIN_EMAILS_DEFAULT).
  3. Skrin "Akaun belum dikaitkan" → taip nama organisasi → Cipta organisasi → anda jadi Super Admin.
  4. Device Groups → cipta kumpulan (cth. Asrama Putera, Kelas 1).
  5. All Devices → Daftar peranti → jana token/QR. Token sekali guna, sah 24 jam.
  6. Peranti muncul di dashboard selepas agent peranti mendaftar (lihat Batasan).
8

Sambung login admin lain & tambah Auth baharu

Peranan disimpan dalam token (custom claims), jadi apa-apa penyedia Firebase Auth berfungsi.

KeperluanCara
Satu akaun baharuSuruh mereka log masuk sekali, kemudian Users & Roles → Hubungkan akaun (e-mel + peranan).
Semua akaun Auth sedia adaGuna skrip di bawah (dry-run dahulu).
Penyedia baharu (Microsoft, GitHub, dll.)Aktifkan di Console → Authentication, kemudian tambah satu baris dalam senarai PROVIDERS di index.html. Selepas itu hubungkan akaun seperti di atas.
export GOOGLE_APPLICATION_CREDENTIALS=/laluan/service-account.json cd my-device-control/functions node ../scripts/link-existing-admins.mjs <orgId> ORG_ADMIN --dry node ../scripts/link-existing-admins.mjs <orgId> ORG_ADMIN
