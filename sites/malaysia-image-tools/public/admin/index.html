Set semula statistik

Kiraan disimpan di Realtime Database pada apps/image-tools/visits dan apps/image-tools/stats. Untuk set semula, padam nod tersebut di Firebase Console. Statistik penggunaan hanya boleh dibaca jika UID anda ada di admins/{UID}: true dalam Realtime Database.
