# apps/tv — Android TV / Google TV

Antara muka 10-kaki sudah tersedia di **`/tv`** dalam apps/web: navigasi D-pad (anak panah, OK, Back), kad besar, kawalan pemain di header.
Diuji: fokus bergerak secara spatial dengan anak panah pada 1920×1080.

Untuk dipasang sebagai app TV: bungkus URL `/tv` dalam Trusted Web Activity (Bubblewrap) dengan `leanback` launcher intent, atau guna app Flutter (apps/mobile) dengan sasaran Android TV. Belum dibina.
